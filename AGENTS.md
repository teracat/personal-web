# Instructions for AI agents

- The editable website source files are in `src/`.
- Do not edit generated files in `docs/` manually; make changes to the corresponding files in `src/`.
- After changing files in `src/`, regenerate their minified versions in `docs/`, preserving the same filenames and relative paths so the published website continues to work.
- `docs/` is the GitHub Pages publishing folder. Include only the files needed to serve the website.
- Before completing a change, check that the HTML references to CSS, JavaScript, and other assets match the generated files in `docs/`.
